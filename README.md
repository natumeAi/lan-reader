<h1 align="center">LAN Reader</h1>

<p align="center">自托管的 EPUB 书架与阅读器 · v1.5</p>

LAN Reader 是一款为个人与可信局域网设计的 EPUB 书架和阅读器。把它部署在自己的设备或服务器上，就能在浏览器中管理 EPUB、安静地阅读，并将书库保留在自己掌控的实例中。

## 为自己的书架而生

如果你希望把 EPUB 图书放在可控的位置，又想在日常使用中拥有清晰的书架、便捷的查找和舒适的阅读界面，LAN Reader 正是为这样的场景准备的。它适合个人书库，也适合在可信的家庭或局域网环境中使用。

这里没有公共书城，也不会替你决定书该如何整理；你的书、文件夹和阅读节奏都由你自己安排。

## 可以做什么

### 把 EPUB 收进书架

导入 EPUB 后，便可在封面书架中浏览自己的藏书。书籍与书库数据由你的自托管实例保存，而不是交给一个陌生的公共书库。

### 整理得顺手，找到得更快

使用文件夹归类书籍，拖放调整书架与文件夹中的顺序；需要回到某一本书时，可以按书名、作者或文件夹搜索。

### 专注于阅读本身

阅读器提供分页阅读、目录导航和插图查看。你还可以按习惯调整主题、字体、字号、边距、行距与字距，让正文更贴近自己的阅读方式。

### 从上次读到的地方继续

每本书都会分别保存阅读位置。再次打开时，你可以继续之前的阅读，而不必重新翻找章节。

## 一次阅读旅程

1. 打开书架，导入想读的 EPUB。
2. 将书籍拖入文件夹，或用搜索快速找到它。
3. 打开书籍后，通过目录跳转内容，并按需要调整阅读外观。
4. 读到合适的位置后直接离开；下次回来，再从已记录的位置继续。

## 立即开始

LAN Reader 从公开 Docker Hub 镜像安装，正常使用不需要构建源码。已安装 Docker Engine 与 Docker Compose 的 WSL 或 Linux 自托管用户，可在项目根目录执行：

```bash
mkdir -p data-lan-reader
sudo chown 1000:1000 data-lan-reader
docker compose pull
docker compose up -d --wait
```

第二行会让数据目录可由镜像中的 `node` 用户写入。启动完成后，在浏览器打开 <http://localhost:4081>，导入第一本 EPUB 即可开始使用。

## 使用边界

- 书籍、书架和服务器保存的阅读位置都留在你的自托管实例中。
- LAN Reader 没有内置认证或权限控制；请只在可信网络中使用。若需远程访问，应在前方部署带认证能力的 HTTPS 反向代理。
- 浏览器中的阅读外观设置和本地缓存按访问地址隔离：更换协议、主机名或端口后，它们不会自动迁移。
- 如需在手机上以 PWA 方式安装，请通过 HTTPS 访问，并在实际要使用的设备上验证安装和阅读体验。
